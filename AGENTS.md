# AGENTS.md

- **Scope**: stay inside this checkout. Confine searches and reads to this repository.
- **Check**: run `bun run check` after each batch of edits. It generates the TanStack route tree, typechecks with `bun check --no-script -b`, lints with `bun lint`, checks formatting with `bun fmt --check`, runs the delayed DOM lookup check, and runs the `scripts/ui` tests with `bun run test:ui`. Lint and format read the oxc configs (`.oxlintrc.json`, `.oxfmtrc.json`). Use `bun check --no-script` for types, never `tsc` or `bunx tsc`.
- **Dev URLs**: connect to `https://fenchem.localhost` with `ignoreHTTPSErrors: true`. Do not resolve to raw localhost ports. Ad-hoc browser scripts require system Chrome (`channel: "chrome"`).
- **OOS1 subpages**: view components live in `apps/web/src/components/prototype/variant-oos1/`: `about-view.tsx`, `products-view.tsx`, `insights-view.tsx`, and `contact-view.tsx`. Their copy lives in the sibling `*-data.ts` files. Page variants live one per folder under `abouts/`, `products/`, `insights/`, and `home/`.
- **Prototype labs**: verify `/prototypes/*` with `bun run test:prototypes`. It runs the typed specs in `apps/web/e2e/prototypes/` in system Chrome against this checkout's portless dev server. Add a lab's interaction checks there as web-first assertions. `test:e2e` serves a production build, where prototype routes return not-found. Verify motion and scroll headlessly; the Browser pane throttles animation frames while hidden.
- **Visual checks**: verify a change that could move pixels with `bun run ui`. Before a refactor, run `bun run ui snap <page>`; after it, `bun run ui diff` compares every snapped baseline. Compare a new variant against its parent with `bun run ui diff <before> <after>`. For a before/after review deliverable, run `bun run ui review` after the diff; it writes one sheet per page family to `.cache/ui/review/`. Pages are dev-server paths such as `"/?variant=oos1&page=about"`. `bun run ui --help` lists the commands, and `--dry-run` prints what a command would render.
