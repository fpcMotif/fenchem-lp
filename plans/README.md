## Design direction in one paragraph

The owner's reference images (bold orange/purple/teal/yellow color-field
photography) map almost one-to-one onto Fenchem's auxiliary division accents
(Food `#E48336`, Cosmetics `#A05EB5`, Agro `#55A695`, Nutrition `#FFF67F`).
Plan 001 therefore adds color **on-brand**: division color-field panels in the
industries section, division-tinted duotone treatment on all category
photography, and Pantone/HEX "specimen" labels that present the color fields
with lab rigor. Built as Variant J (clone of the production-recommended
Variant H) so H stays the untouched rollback and the switcher gives H↔J
side-by-side comparison.

## Findings considered and rejected

- **Editing Variant H in place**: rejected — the repo's decision workflow
  (`prototype/NOTES.md`, the variants registry) is side-by-side comparison;
  keeping H untouched preserves the baseline and instant rollback.
- **Using all six division accents / accent-colored headlines**: rejected —
  the 2026-08 design review (`docs/brand/landing-variants-design-review.md`)
  documented Variant E's six-hue page as a failure of restraint; J uses three
  hues, each only as wayfinding for its own division, per the brand book.
- **New photography / art direction**: out of code scope — a content task the
  design review already tracks; the duotone treatment is the code-side
  mitigation until real origin photography lands.
- **Migrating `landing-page.tsx` off the retired editorial palette**: not
  planned here — that component is not rendered on `/` (the route renders the
  variant registry), and per `NOTES.md` it gets rewritten when a variant wins.
  Flagged for the fold-in milestone instead.
- **Dark mode for the landing variants**: rejected for now — the brand book's
  canvas is Clean White; the variants are deliberately single-theme.
