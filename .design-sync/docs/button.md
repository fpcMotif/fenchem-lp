Primary action control — default/destructive/outline/secondary/ghost/link variants, three sizes + icon, built on Base UI Button with CVA variants.

## Usage

```tsx
<Button>Request a sample</Button>
<Button variant="outline" size="sm">Learn more</Button>
```

Props: `variant` (default | destructive | outline | secondary | ghost | link), `size` (default | sm | lg | icon), plus all Base UI Button props. Use `buttonVariants({ variant, size })` to style a link as a button.
